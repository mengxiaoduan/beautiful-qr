# 🌈 花漾二维码 (Beautiful QR)

一个纯前端的**优美二维码生成器**：放入链接或图片、起个好名字，就得到一张配色和形态都会"表达"这个名字的漂亮二维码。

**在线使用**：https://mengxiaoduan.github.io/beautiful-qr/

## ✨ 特性

- **名字即设计**：内置关键词主题库（"咖啡"→咖啡棕、"音乐"→音乐紫、"露营"→森林绿……），没命中关键词也会根据名字哈希从精选色板中选色，中心图案自动匹配表情或取名字首字
- **四种二维码形态**：圆点 / 圆润 / 液态（相邻模块自动融合）/ 方块
- **渐变配色 + 美化定位角与对齐图案**，所有样式都在高容错级别下生成，扫码可靠
- **图片模式**：图片压缩后直接内嵌进二维码数据，扫码打开本站展示页查看大图——**不依赖任何第三方图床，链接永久有效**；也可以粘贴图片直链，扫码直接看原图
- **本地生成**：不上传任何数据；生成历史保存在本机 localStorage
- **解码自测报告**：[selftest.html](selftest.html) 用 jsQR 对每种风格 × 每种内容做真实扫码回验

## 📱 使用

手机/电脑浏览器打开即可，无需安装。生成后「保存 PNG」或「复制」到剪贴板，即可打印或分享。

## 🔧 技术

- 二维码矩阵：[qrcode-generator](https://www.npmjs.com/package/qrcode-generator)（已启用 UTF-8 编码）
- 美化渲染：原生 Canvas 自绘（液态圆角、渐变、定位角重绘、对齐图案美化、中心 Logo 挖孔）
- 图片内嵌：Canvas 压缩至 WebP/JPEG ≤ 2.1KB，Base64URL 编码后放进 `#v=` 片段，扫码打开同一页面的展示模式
- 解码验证：[jsQR](https://github.com/cozmo/jsQR)
